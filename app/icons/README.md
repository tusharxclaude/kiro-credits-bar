# Icons

All icons here are **original artwork** generated by [`tools/make_icons.py`](../../tools/make_icons.py):

- `icon.png`: the app icon, a progress bar on a purple tile.
- `tray-green.png`, `tray-amber.png`, `tray-red.png`, `tray-grey.png`: the tray icon, the same bar
  tinted by pace (grey means the reading is stale).

The purple follows the colours used on kiro.dev. **No Kiro logo, mascot or other Kiro artwork is
included**, and the app is not affiliated with Kiro. Please keep it that way unless the Kiro team
has given permission.

Regenerate with `python3 -I tools/make_icons.py` (no dependencies besides Python 3).

## Platform icon files

`icon.ico` (Windows, required by the build), `icon.icns` (macOS) and the `32x32`, `128x128` and
`128x128@2x` PNGs are generated from `icon.png` with Tauri's icon tool:

```sh
cd app && cargo tauri icon icons/icon.png -o /tmp/icons   # then copy those five files into icons/
```
